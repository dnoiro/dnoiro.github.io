# Portfolio usability organization

The homepage retains its existing layout, palette, and Pixelify Sans font.

## Homepage focus — November 2026

The introduction and primary link lead with PCB design. Homepage sections now follow PCB work, selected Altium training, FPGA work, and the existing rocket launch. The four featured training badges are Altium PCB Design Essentials, Skilled Engineer, Emerging Engineer, and Mixed-Signal Simulation; Cadence credentials remain on their related PCB and FPGA pages. Larger homepage badges make the Altium training easier to scan. The rocket section, recording, and poster are unchanged.

## Rules applied

- Consistency: PCB and FPGA navigation both open area overviews, followed by project detail pages. Global navigation stays the same across pages; an active area remains highlighted on its project pages.
- Descriptive links: actions name the destination or evidence, replacing vague Details labels and competing routes in the homepage cards.
- Orientation: project breadcrumbs show Home, the parent area, and the current project. Each detail page ends with a clear return to its parent.
- Progressive disclosure: category pages summarize work; project pages contain detail and related credentials. MATLAB has its own detail page. Older coursework and large certificate galleries remain available on demand.
- Scannability: core detail pages summarize context, contribution/tools, and evidence before the longer narrative.
